# Energy Studio · 交互与三维组态路线图

> 项目为独立脱敏演示，全部设备与读数均使用模拟数据；不引入长安能源生产代码、账号、接口或配置。

## 需求记录：2D/3D 应为同工作台视图切换（已记录，暂不实施）

- **原始需求（2026-10-29）**：2D/3D 切换不是“离开 3D 页面再返回 2D”，应在**同一个工作台**直接切换视图。
- 两个视图共享同一份场景数据、选中对象与编辑上下文，避免路由跳转、重复加载及状态丢失。
- 切换过程中应保持设备标识与草稿编辑状态；二维拓扑位置与三维空间变换分别存储，避免互相覆盖。
- **优先级：非当前核心（后续调整）**。现有 V2.1/V2.2 的独立 3D 编辑入口只是过渡方案。
- **验收标准（后续版本）**：工作台内点击 2D / 3D 标签实时切换，无页面刷新/路由离开，状态不丢失，保存/撤销一致。

## V2.2 数据约定

- 保留 `PageSchema.schemaVersion = 1.0.0` 和已有 `pipe.points[]`，使 V2.0 画布与草稿格式兼容。
- 为管线增加非破坏性扩展 `pipe.threeD`：
  - `points: [{id,x,y,z}]`：三维控制点，使用世界坐标；
  - `diameter`：公称直径（DN50 / 80 / 100 / 125 / 150 / 200）；
  - `from`、`to`：可选设备 ID 与入口/出口端口。
- 已连接端口随设备三维变换重新计算；二维 `pipe.points[]` 保持三维路径到平面的投影。
- 使用程序化三维管道与圆角弯头作为 V2.2 演示，不等同于具备工程精度的 CAD 模型。
- 草稿保存在浏览器 `energy-studio-demo-v2`；已发布版本不由 3D 编辑器直接覆盖。

## 验收清单

1. 新建管线，从两个设备的端口连线；模型显示真实体积，不是地面二维线。
2. 切换 DN50 / DN125 / DN200，管线粗细发生对应变化。
3. 选择管线、增加/删除折点，拖动三维控制点改变管线路径和标高。
4. 移动或旋转已连接设备，管道端点跟随；重新加载草稿后连接关系保留。
5. 撤销/重做、保存草稿、导出 JSON 能保留全部管线属性。
6. 2D 界面仍能读取 `pipe.points[]`；发布版本不被草稿自动修改。
7. 多次切换设备编辑/管线编辑，不出现 WebGL 上下文、重复网格或事件泄漏。
