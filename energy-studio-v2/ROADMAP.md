# Energy Studio · 交互与三维组态路线图

> 项目为独立脱敏演示，全部设备与读数均使用模拟数据；不引入长安能源生产代码、账号、接口或配置。

## 需求记录：2D/3D 应为同工作台视图切换（已记录，暂不实施）

- **原始需求（2026-10-29）**：2D/3D 切换不是“离开 3D 页面再返回 2D”，应在**同一个工作台**直接切换视图。
- 两个视图共享同一份场景数据、选中对象与编辑上下文，避免路由跳转、重复加载及状态丢失。
- 切换过程中应保持设备标识与草稿编辑状态；二维拓扑位置与三维空间变换分别存储，避免互相覆盖。
- **优先级：非当前核心（后续调整）**。现有 V2.1/V2.2 的独立 3D 编辑入口只是过渡方案。
- **验收标准（后续版本）**：工作台内点击 2D / 3D 标签实时切换，无页面刷新/路由离开，状态不丢失，保存/撤销一致。

## V2.2 数据约定

- 保留 `PageSchema.schemaVersion = 1.0.0` 和已有 `pipe.points[]`，使 V2.0 画布与草稿格式兼容。
- 为管线增加非破坏性扩展 `pipe.threeD`：
  - `points: [{id,x,y,z}]`：三维控制点，使用世界坐标；
  - `diameter`：公称直径（DN50 / 80 / 100 / 125 / 150 / 200）；
  - `from`、`to`：可选设备 ID 与入口/出口端口。
- 已连接端口随设备三维变换重新计算；二维 `pipe.points[]` 保持三维路径到平面的投影。
- 使用程序化三维管道与圆角弯头作为 V2.2 演示，不等同于具备工程精度的 CAD 模型。
- 草稿保存在浏览器 `energy-studio-demo-v2`；已发布版本不由 3D 编辑器直接覆盖。

## 验收清单

1. 新建管线，从两个设备的端口连线；模型显示真实体积，不是地面二维线。
2. 切换 DN50 / DN125 / DN200，管线粗细发生对应变化。
3. 选择管线、增加/删除折点，拖动三维控制点改变管线路径和标高。
4. 移动或旋转已连接设备，管道端点跟随；重新加载草稿后连接关系保留。
5. 撤销/重做、保存草稿、导出 JSON 能保留全部管线属性。
6. 2D 界面仍能读取 `pipe.points[]`；发布版本不被草稿自动修改。
7. 多次切换设备编辑/管线编辑，不出现 WebGL 上下文、重复网格或事件泄漏。


## V2.3 具体实现与约束

- **设备模型库**：内置可编辑的程序化设备模型：循环水泵、空调机组、阀门、储罐、智能仪表。
- **本地 GLB 导入**：用户可选择 glTF 2.0 `.glb` 文件替换某台设备的模型；文件仅保存在当前浏览器的 IndexedDB 中，不上传外部服务器。模型 ID 写入 `object.threeD.modelId`；其他电脑/浏览器仅有模型 ID 不具备原始文件，需重新导入。
- **安全与负载限制**：导入文件上限 8 MB，三角面数上限 20 万。当前内置模型仍为简化程序化模型，精细高保真效果需要专门制作/导入 GLB，并不等同于完整 CAD。
- **设备动效**：水泵转子、空调风机、阀门开度、储罐液位、状态指示灯；附加 `threeD.runState`、`threeD.animationSpeed`、`threeD.level`（GLB 自带动画则用 AnimationMixer）。
- **管线动效**：沿三维管道路径移动的流向标识，属性 `threeD.flowState`、`threeD.flowSpeed`；通过用户开关暂停。
- **性能**：默认 15 FPS 动画节能模式，可选 24 / 30 FPS；拖动视角及编辑时提高交互帧率；页面隐藏时停止渲染；停止动画后静止场景按需绘制。
- **兼容性**：保留 `PageSchema.schemaVersion=1.0.0`、对象 ID 及 2D 投影，扩展字段不影响现有画布；保存草稿不会修改 `published`。
- **离线限制**：当前 3D 编辑器使用外部 CDN 提供 Three.js 和 GLTFLoader，未承诺离线运行。首次联网失败时 3D 编辑器可能无法启动。

### V2.3 验收用例

1. 为水泵、阀门、储罐分别指定内置模型，切换设备、保存及刷新后模型选择仍保留。
2. 旋转水泵转子；停止/启动阀门动效；改变储罐液位；模拟异常改变设备状态指示。
3. 水/电/气管线流向动效可单独暂停或调节速度。
4. 全局暂停动画后停止持续渲染；节能 15 FPS 与流畅 30 FPS 模式可切换。
5. 合法 GLB 导入后显示模型、可平移/旋转/缩放；非法格式或过大模型给出明确错误。
6. 刷新后从本地 IndexedDB 取回 GLB；另一浏览器缺失模型时显示安全回退模型。
7. 拖动/复制设备不会丢失 `threeD.modelId`、动画设置、管线连接信息。
8. Undo/Redo、草稿保存、JSON 导出、2D 视图读取、published 隔离无回归。

> 以上为验收清单；目前完成了代码与静态验证，尚未完成真实浏览器 WebGL 全流程验收。
